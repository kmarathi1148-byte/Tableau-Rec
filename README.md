Tableau Data Visualization and Business Intelligence Projects

📌 Project Overview

This repository contains 15 practical experiments based on Tableau Data Visualization and Business Intelligence.

The projects focus on analyzing different datasets, creating interactive dashboards, identifying business trends, and presenting meaningful insights through various Tableau charts and visualizations.

The main objective is to develop practical skills in data analysis, data visualization, dashboard creation, and business intelligence.

🎯 Objectives

- Understand data visualization using Tableau.
- Create different types of charts and graphs.
- Analyze business data and identify trends.
- Build interactive dashboards.
- Perform sales and marketing analysis.
- Understand forecasting and predictive analysis.
- Apply advanced visualization techniques.
- Generate meaningful insights from datasets.

🛠️ Tools and Technologies

- Tableau Desktop / Tableau Public
- Microsoft Excel
- CSV Datasets
- Data Visualization
- Business Intelligence
- Dashboard Development

📊 Experiments Included

Experiment 01 – Starbucks Sales and Marketing Analysis

- Sales trend analysis across Tea and Coffee categories using an Area Chart.
- Total sales distribution using a Pie Chart.
- Correlation between Sales and Marketing Expenses using a Scatter Plot.

Experiment 02 – El Horno's Pizza BI Analysis

- Sales trend analysis for Pizza and Burger categories.
- Sales distribution using a Pie Chart.
- State-wise Pizza and Burger sales analysis.
- Marketing campaign effectiveness analysis.
- Correlation between Sales and Marketing Expenses.

Experiment 03 – Global Superstore Chart Creation

- Pareto Chart for running total of profit.
- Funnel Chart for potential revenue analysis.
- Waterfall Chart for sales analysis.
- Control Chart with parameter-based control limits.

Experiment 04 – UK Bank Data Analysis

- Map Chart showing transactions by region.
- Pie Chart displaying transactions by gender.
- Histogram for age and transactions.
- Histogram for balance and transactions.
- Tree Map showing transactions by job classification.
- Interactive Dashboard using Action Filters.

Experiment 05 – Edureka Interactive Dashboard Creation

- Created an interactive dashboard for Edureka's popular courses.
- Used different dashboard objects and visualizations.

Experiment 06 – Halloween Event Planning Dashboard

- Precipitation level analysis.
- Future event forecasting.
- Year-by-year variation analysis.
- Visitor strength analysis.

Experiment 07 – Global Superstore Sales Trend Forecasting

- Sales forecasting using Global Superstore 2016 data.
- Predicted future sales trends over six quarters.

Experiment 08 – Movie Ratings and Budgets Analysis

- Movie budget analysis across genres.
- Correlation between audience and critic ratings.
- Movie releases by genre over time.
- Comparison of ratings over time.
- Top three movies based on audience and critics' ratings.
- Created an interactive dashboard.

Experiment 09 – Global Superstore Advanced Charting

Created the following advanced charts:

- Bar-in-Bar Chart
- Bullet Chart
- Barbell Chart
- Lollipop Chart
- Bump Chart

Experiment 10 – Adventure Works BI Case Study

- Bar-in-Bar Chart comparing Sales and Profit by country.
- Gantt Chart for order quantity differences.
- Step and Jump Line Chart for cumulative sales.
- Funnel Chart for profit by region.
- Area Funnel Chart for order quantity.
- Word Clouds based on Sub-category, Profit, Sales, and Country.

Experiment 11 – Rainfall Forecast Report

- Analyzed 34 years of historical weather data.
- Used rainfall data from 2011 to 2018.
- Created a rainfall forecast report for 2019–2020.

Experiment 12 – African Mobile Data Visualization

- Visualized profit across different countries.
- Analyzed sales trends using African Mobile Data.

Experiment 13 – Hierarchical Data Visualization Using Drill-Down

- Created a hierarchy of Country, State, and City.
- Performed drill-down operations.
- Demonstrated changing colors using the drill-down concept.

Experiment 14 – Student Academic Performance Segmentation

- Analyzed student academic performance.
- Created Good, Average, and Bad performance segments.
- Evaluated Math Test and Writing Test results.

Experiment 15 – Park Visiting Trend Stacked Bar Chart

- Created a Stacked Bar Chart using park visiting trend data.
- Displayed labels at the end of each bar.
